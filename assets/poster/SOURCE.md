# Event poster

The hero illustration is an original drawing of two male karigars tying a bamboo joint. The people are invented. They are not Anil Samanta, Paritosh Kumar Mondal, Santosh Mondal, or any other named person. Event name, date and venue stay in HTML.

The older `event-poster.jpg` and `event-poster.gif` remain in this folder. That GIF only moved lights and particles, and it is no longer used on the page.

| File | What it is |
| --- | --- |
| `karigar-vijay-sammelan-2026-master.webp` | Static master, 1280×720. A frame from the tying sequence. Not upscaled. |
| `karigar-vijay-sammelan-2026-static.webp` | Same scene, smaller WebP, used when reduced motion is requested and when the visitor pauses the GIF. |
| `karigar-vijay-sammelan-2026-hero.gif` | Animated GIF of the same tying action. Measured 14 October 2026: 720×405, 48 frames, 2,144,897 bytes, loop 0. Delays are 120 ms on 23 frames and 130 ms on 25 frames. Total 6.01 seconds, about 8 fps. |

The motion comes from a generated clip whose first and last frames match, with the hands-down pose in the middle, then encoded with ffmpeg. A generator mark in the paper border was covered with `delogo` before the public files were saved. The GIF has no audio.
